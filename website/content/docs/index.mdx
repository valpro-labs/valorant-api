A typed TypeScript client for [valorant-api.com](https://valorant-api.com/) with full type safety powered by [Zod](https://zod.dev/).

## Installation

```bash
npm install @valpro-labs/valorant-api
```

## Quick start

```ts
import { ValorantApi } from '@valpro-labs/valorant-api';

const api = new ValorantApi({ language: 'en-US' });

// Get all agents
const agents = await api.agentsEndpoints.getAgentsV1();

// Get current game version
const version = await api.versionEndpoint.getVersionV1();
```
